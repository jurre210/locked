# Deepcast

A fishing word game: answer the prompt, and the rarer your answer, the deeper your line sinks.
Play: https://jurre210.github.io/locked/

- `index.html` is the built single-file game.
- Edit `src.html`, `data.js` (answer bank) and `mp.js` (friends mode), then run `python build.py`.

The old 3D model viewer lives in git history (last commit 55f7269).
